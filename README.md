# Python-Ethical-Hacking-mini-projects-

Project Title: Python Ethical Hacking Mini Projects

Description: This repository contains a collection of mini-projects that demonstrate fundamental concepts of ethical hacking using Python. Each project is designed to give hands-on experience with real-world hacking and cybersecurity tasks, such as network scanning, vulnerability detection, and packet sniffing.

Technologies Used:

Python 3.x

Scapy (for network manipulation)

Kali Linux (for penetration testing)

VirtualBox (for creating isolated virtual environments)

Features: ▪ MAC Address Changer: A tool to change your device's MAC address for privacy or bypassing network restrictions. ▪ Network Scanner: A Python script that identifies devices connected to a network. ▪ ARP Spoofing: A simple tool for performing ARP spoofing attacks to intercept network traffic. ▪ Packet Sniffer: A script to capture and analyze network packets in real time. ▪ Keylogger: A Python-based keylogger for monitoring keyboard inputs (ethical use only). ▪ Backdoor: A simple backdoor script to remotely control a system (ethical use only). ▪ Vulnerability Scanner: A scanner to identify common vulnerabilities in web applications, such as XSS (Cross-Site Scripting).
